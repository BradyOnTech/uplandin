# Sharptail environment direction

`landform-concept-v1.png` is a generated design study, not a capture of the game or a runtime asset. The built-in image-generation tool created it on September 27, 2026; the exact prompt is in `landform-concept-v1-prompt.txt`.

Use its overlapping shoulders, irregular exposure bands, sheltered grass masses and distant building reveal as composition references. Preserve the game's authored property coordinates, habitat and routes. Its extra distant cliffs, tree density and fine surface detail are not requirements for the playable terrain.

The source PNG is kept out of the public build. Actual acceptance requires ordinary eye-level High/Lightweight views and a connected route through the implemented landscape; this concept cannot establish implementation quality or mobile performance.
